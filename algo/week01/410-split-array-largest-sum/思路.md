# LC 410 · 分割数组的最大值 — 解题思路

## 题意

将数组 `nums` 分成 `k` 个**非空连续**子数组，最小化「各段和的最大值」。

## 核心思路（二分答案）

- **单调性**：允许的"段和上界" `maxSum` 越大 → 每段能装更多 → 需要的段数越少。
- **check(maxSum)**：贪心——逐项累加，超过 `maxSum` 就开新段；统计段数是否 ≤ `k`。
- **搜索区间**：`[max(nums), sum(nums)]`。

## 与 LC 1011 的同构关系

| 410 | 1011 |
|-----|------|
| 数组 `nums` | 包裹重量 `weights` |
| 段数 ≤ `k` | 天数 ≤ `days` |
| 段和上界 `maxSum` | 船容量 `cap` |

代码结构完全相同，只是变量名不同。刷完一道另一道可以直接默写。

## 复杂度

- **时间**：O(n · log(sum - max))。
- **空间**：O(1)。

## 易错点

1. **"连续"子数组**：不可重排，贪心必须按原序。
2. **`k = 1`**：整个数组一段，答案就是 `sum(nums)`；二分自然处理。
3. **`k = n`**：每个元素一段，答案就是 `max(nums)`；同样自然处理。
