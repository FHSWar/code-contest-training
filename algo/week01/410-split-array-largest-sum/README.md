# 410. 分割数组的最大值

- **链接**：[LeetCode 410](https://leetcode.cn/problems/split-array-largest-sum/)
- **难度**：困难
- **标签**：数组、二分查找、动态规划、贪心

## 题目描述

给定一个非负整数数组 `nums` 和一个整数 `k`，将 `nums` 分成 `k` 个**非空连续**子数组（不可重排）。

使这 `k` 个子数组各自和的**最大值最小化**，返回这个最小化后的最大值。

## 示例

```text
输入：nums = [7,2,5,10,8], k = 2
输出：18
解释：分成 [7,2,5] 和 [10,8]，各段和为 14 和 18，最大值 18。这是所有分法中最大值最小的。
```

```text
输入：nums = [1,2,3,4,5], k = 2
输出：9
解释：分成 [1,2,3,4] 和 [5]（和 10,5）不如 [1,2,3] 和 [4,5]（和 6,9），最优为 9
```

## 约束

- `1 <= nums.length <= 1000`
- `0 <= nums[i] <= 10^6`
- `1 <= k <= min(50, nums.length)`
