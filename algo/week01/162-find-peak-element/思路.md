# LC 162 · 寻找峰值 — 解题思路

## 题意

数组 `nums` 无重复，`nums[-1] = nums[n] = -∞`（边界视为负无穷），返回**任一**峰值下标（严格大于相邻）。要求 **O(log n)**。

## 核心思路

- `nums[mid] < nums[mid + 1]` → 右侧存在一个"上坡"，右半一定有峰；否则 `mid` 处或左半有峰。
- 用 **闭区间** `[left, right]`、`while left < right` 循环，每轮缩半，最终 `left == right` 即峰。

## 为什么一定能找到峰？

因为 `nums[-1] = -∞`，若 `nums[0] > nums[1]` 则 0 就是峰；否则从 0 开始"上坡"，总会到达一个顶点（不可能无限上升，因为 `nums[n] = -∞`）。二分只是利用了这个单调性来加速。

## 复杂度

- **时间**：O(log n)。
- **空间**：O(1)。

## 易错点

1. **区间用 `[left, right]`（闭区间）**：因为 `right` 本身可能是峰，不能排除；循环条件用 `left < right` 而非 `left <= right`（否则死循环）。
2. **`mid + 1` 不越界**：`left < right` 保证 `mid < right`，即 `mid + 1 <= right < n`，安全。
3. **返回任意峰**：测试不能硬编码 expected（多峰时），需验证 `isPeak` 性质。
