# 162. 寻找峰值（Find Peak Element）

- **链接**：[LeetCode 162](https://leetcode.cn/problems/find-peak-element/)
- **难度**：中等
- **标签**：数组、二分查找

## 题目描述

峰值元素是指**严格大于左右相邻值**的元素。给定数组 `nums`，找到**任意一个**峰值元素并返回其下标。

数组可能包含多个峰值，返回任一即可。可以假设 `nums[-1] = nums[n] = -∞`（数组两端外视为负无穷）。

要求时间复杂度 **O(log n)**。

## 示例

```
输入：nums = [1,2,3,1]
输出：2
解释：nums[2] = 3 是峰值
```

```
输入：nums = [1,2,1,3,5,6,4]
输出：5（或 1，返回任一峰值下标即可）
解释：nums[5] = 6 和 nums[1] = 2 都是峰值
```

## 约束

- `1 <= nums.length <= 1000`
- `-2^31 <= nums[i] <= 2^31 - 1`
- 对于所有有效的 `i`，`nums[i] != nums[i + 1]`（相邻元素不相等）
