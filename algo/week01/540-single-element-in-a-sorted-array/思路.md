# LC 540 · 有序数组中的单一元素 — 解题思路

## 题意

有序数组中，除一个元素出现一次外，其余均出现两次。找出那个单一元素。要求 **O(log n)**、**O(1)** 空间。

## 核心思路

- 单一元素之前，配对从偶数下标开始：`nums[0]==nums[1]`、`nums[2]==nums[3]`……
- 单一元素之后，配对被"错位"一格。
- **关键判断**：将 `mid` 强制对齐到偶数位（`mid -= mid & 1`），然后检查 `nums[mid] == nums[mid+1]`：
  - 相等 → 配对未被打破，单一元素在右侧，`left = mid + 2`。
  - 不等 → 配对已错位或 `mid` 就是单一元素，`right = mid`。

## 简化技巧

`mid -= mid & 1`（等价于 `mid &= ~1`）可以把奇数 `mid` 拉回前一个偶数，从而消除奇偶分支，统一为一种判断。

## 复杂度

- **时间**：O(log n)。
- **空间**：O(1)。

## 易错点

1. **`left = mid + 2`**：因为 `mid` 和 `mid+1` 都是同一对，可以跳过两个。
2. **数组长度为奇**（`2k + 1`），`right` 初始值为 `nums.length - 1`（偶数下标）。
3. **单元素数组**：`left == right` 直接返回。
