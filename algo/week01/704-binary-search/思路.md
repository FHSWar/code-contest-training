# LC 704 · 二分查找 — 解题思路

## 题意

在**升序**数组 `nums` 中查找 `target` 的下标；不存在则返回 `-1`。要求 **O(log n)**，即不能线性扫描。

## 核心思路

- 数组有序 → 任取中点 `nums[mid]`，与 `target` 比较即可**排除一半区间**，重复直到找到或区间为空。
- 本质是维护一个**搜索区间**，保证 `target`（若存在）始终落在当前区间内；每轮根据 `nums[mid]` 与 `target` 的大小关系收缩区间。

## 两种等价写法（务必两套都会）

| 对比项 | **闭区间 `[left, right]`** | **左闭右开 `[left, right)`** |
| --- | --- | --- |
| 初值 | `left = 0`, `right = n - 1` | `left = 0`, `right = n` |
| 循环 | `while (left <= right)` | `while (left < right)` |
| `nums[mid] < target` | `left = mid + 1` | `left = mid + 1` |
| `nums[mid] > target` | `right = mid - 1` | `right = mid` |
| 命中 | 直接返回 `mid` | 直接返回 `mid` |
| 未命中 | 结束时 `left > right` | 结束时 `left == right`，区间为空 |

- **闭区间**：和「在 `[0, n-1]` 里找下标」的直觉一致，适合 704 入门。
- **左闭右开**：与 **LC 35（搜索插入位置）、LC 34（左右边界）** 及 `bisect` / `partition_point` 类语义统一，建议作为**后续周的主模板**。

本目录 `solution.ts` 中两种实现并列；`solution.py` / `solution.rs` 采用**左闭右开**，与 `searchHalfOpen` 及后续 35 / 34 等题模板一致。

## 复杂度

- **时间**：O(log n)，每轮区间长度大约减半。
- **空间**：O(1)，仅若干下标变量。

## 易错点

1. **`mid` 溢出**：使用 `left + Math.floor((right - left) / 2)`（或语言等价写法），避免 `left + right` 在极大下标时溢出。
2. **区间与分支一致性**：闭区间必须用 `<=` 与 `mid ± 1` 配套；左闭右开必须用 `<` 与 `right = mid` 配套，**不要混用两套规则**。
3. **空数组**：若题目允许 `n = 0`，需在循环前特判（本题约束 `n >= 1`，可略）。
