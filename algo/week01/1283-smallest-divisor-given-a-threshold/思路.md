# LC 1283 · 使结果不超过阈值的最小除数 — 解题思路

## 题意

给定 `nums` 和 `threshold`，找最小正整数除数 `d`，使 `sum(ceil(nums[i] / d))` ≤ `threshold`。

## 核心思路（二分答案）

- **单调性**：`d` 越大 → 每项上取整越小 → 总和越小。
- **check(d)**：`sum(ceil(nums[i] / d))` ≤ `threshold`？
- **搜索区间**：`[1, max(nums)]`。

## 复杂度

- **时间**：O(n · log(max(nums)))。
- **空间**：O(1)。

## 易错点

1. **与 LC 875 几乎同构**：只是变量名不同（`piles/h` → `nums/threshold`）。如果 875 写熟了，本题可以秒做。
2. **Rust 溢出**：同 875，累加器应使用 `i64`。
