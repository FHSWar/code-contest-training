# LC 34 · 在排序数组中查找元素的第一个和最后一个位置 — 解题思路

## 题意

升序数组 `nums`（可含重复），返回 `target` 的起止下标 `[first, last]`；不存在则 `[-1, -1]`。要求 **O(log n)**。

## 核心思路

- 问题转化为两次 **lower_bound**：
  1. `first = lower_bound(target)`：第一个 `≥ target` 的下标。
  2. `last = lower_bound(target + 1) - 1`：第一个 `≥ target+1` 的下标减一。
- 若 `first` 越界或 `nums[first] != target`，则 `target` 不存在。

## 模板（左闭右开 lower_bound）

```text
left = 0, right = n
while left < right:
    mid = left + (right - left) // 2
    if nums[mid] < x:   left = mid + 1
    else:                right = mid
return left   // 第一个 >= x 的位置
```

与 [LC 35](../35-search-insert-position/) 的 `searchInsert` 完全一致；本题只是调用两次并做存在性判断。

## 复杂度

- **时间**：O(log n)，两次二分各 O(log n)。
- **空间**：O(1)。

## 易错点

1. **`target + 1` 溢出**：语言层面，Python 无限精度无忧；TS/Rust 在 LeetCode 约束内安全（`target ≤ 10^9`）。
2. **空数组**：`first = 0`，但 `first == n` 时应直接返回 `[-1, -1]`。
3. **与 `bisect_left` / `bisect_right` 的关系**：`first = bisect_left(target)`，`last = bisect_right(target) - 1 = bisect_left(target+1) - 1`，两种理解等价。
