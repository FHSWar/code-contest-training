# LC 153 · 寻找旋转排序数组中的最小值 — 解题思路

## 题意

升序、无重复数组经旋转，找最小值。要求 **O(log n)**。

## 核心思路

- `nums[mid] > nums[right]` → 旋转断点在 `(mid, right]`，最小值在右半，`left = mid + 1`。
- 否则 `nums[mid] <= nums[right]` → `[left, mid]` 段包含最小值（`mid` 本身可能就是最小），`right = mid`。
- 结束时 `left == right`，指向最小值。

## 为什么比较 `nums[mid]` 和 `nums[right]` 而不是 `nums[left]`？

若比较 `nums[mid]` 和 `nums[left]`：当 `nums[mid] >= nums[left]` 时无法确定最小值在左还是右（想想未旋转的情况 `[1,2,3,4]`）。而与 `nums[right]` 比较可以可靠判断断点方位。

## 复杂度

- **时间**：O(log n)。
- **空间**：O(1)。

## 易错点

1. **区间**：用 `[left, right]`（闭区间）+ `while left < right`；`right = mid` 保留 `mid` 为候选。
2. **完全未旋转**：如 `[1,2,3]`，每步都走 `right = mid`，最终 `left = 0`，正确。
3. **与 LC 33 比较**：33 是"搜索 target"需要判断有序段 + 值域；153 只需找断点，逻辑更简。
