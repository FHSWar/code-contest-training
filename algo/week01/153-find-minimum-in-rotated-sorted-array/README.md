# 153. 寻找旋转排序数组中的最小值

- **链接**：[LeetCode 153](https://leetcode.cn/problems/find-minimum-in-rotated-sorted-array/)
- **难度**：中等
- **标签**：数组、二分查找

## 题目描述

已知一个长度为 `n` 的数组，预先按照升序排列，经由 1 到 `n` 次旋转后得到输入数组。元素值**互不相同**。

给定旋转后的数组 `nums`，返回数组中的**最小元素**。

要求时间复杂度 **O(log n)**。

## 示例

```text
输入：nums = [3,4,5,1,2]
输出：1
解释：原数组 [1,2,3,4,5] 旋转 3 次得到
```

```text
输入：nums = [4,5,6,7,0,1,2]
输出：0
```

```text
输入：nums = [11,13,15,17]
输出：11
解释：未旋转（或旋转 n 次等价），最小值就是第一个元素
```

## 约束

- `n == nums.length`
- `1 <= n <= 5000`
- `-5000 <= nums[i] <= 5000`
- `nums` 中的所有整数**互不相同**
