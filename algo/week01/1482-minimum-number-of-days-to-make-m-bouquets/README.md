# 1482. 制作 m 束花所需的最少天数

- **链接**：[LeetCode 1482](https://leetcode.cn/problems/minimum-number-of-days-to-make-m-bouquets/)
- **难度**：中等
- **标签**：数组、二分查找

## 题目描述

花园中有 `n` 朵花，第 `i` 朵花会在 `bloomDay[i]` 天开放。

每束花需要**相邻的** `k` 朵已开放的花。给定整数 `m`（需要 `m` 束花），返回需要等待的**最少天数**。如果无法制作 `m` 束花则返回 `-1`。

关键约束：每束花必须用**连续下标**的 `k` 朵花，且每朵花只能属于一束。

## 示例

```text
输入：bloomDay = [1,10,3,10,2], m = 3, k = 1
输出：3
解释：第 3 天开放的花：[✓,✗,✓,✗,✓]，每束只要 1 朵，3 束够了
```

```text
输入：bloomDay = [1,10,3,10,2], m = 3, k = 2
输出：-1
解释：需要 3×2=6 朵花，但只有 5 朵，无解
```

```text
输入：bloomDay = [7,7,7,7,12,7,7], m = 2, k = 3
输出：12
解释：第 12 天全开，连续 3 朵的段有 [0-2] 和 [4-6]，刚好 2 束
```

## 约束

- `1 <= bloomDay.length <= 10^5`
- `1 <= bloomDay[i] <= 10^9`
- `1 <= m <= 10^6`
- `1 <= k <= bloomDay.length`
