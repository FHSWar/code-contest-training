# LC 74 · 搜索二维矩阵 — 解题思路

## 题意

`m × n` 矩阵，每行升序且下一行首 > 上一行末，判断 `target` 是否存在。

## 核心思路

- 整个矩阵可视为**一维递增数组**，长度 `m * n`。
- 一维下标 `mid` 映射为行列：`row = mid / n`，`col = mid % n`。
- 标准闭区间二分即可。

## 复杂度

- **时间**：O(log(m·n))。
- **空间**：O(1)。

## 易错点

1. **映射公式**：用列数 `n` 做除/模，不是 `m`。
2. **闭区间**：`right = m * n - 1`，`while left <= right`。
3. **与 LC 240 区别**：240 的矩阵只保证行列各自递增，不能展平为一维；240 用"右上角"搜索，时间 O(m + n)。
