# LC 33 · 搜索旋转排序数组 — 解题思路

## 题意

原升序、无重复数组在某处旋转（如 `[4,5,6,7,0,1,2]`），找 `target` 下标，不存在返回 `-1`。要求 **O(log n)**。

## 核心思路

- 二分后 `[left, mid]` 与 `[mid, right]` 中**至少一段有序**（旋转点只可能在其中一段）。
- 先判断哪段有序（`nums[left] <= nums[mid]` → 左段有序），再看 `target` 是否落在有序段的值域内，决定收缩方向。

## 分支逻辑

```text
if nums[left] <= nums[mid]:            ← 左半有序
    if nums[left] <= target < nums[mid]:  → right = mid - 1
    else:                                  → left = mid + 1
else:                                   ← 右半有序
    if nums[mid] < target <= nums[right]: → left = mid + 1
    else:                                  → right = mid - 1
```

## 复杂度

- **时间**：O(log n)。
- **空间**：O(1)。

## 易错点

1. **`<=` vs `<`**：`nums[left] <= nums[mid]` 要用 `<=`（`left == mid` 时左段只有一个元素，仍"有序"）。
2. **闭区间**：本题用 `while left <= right` + `mid ± 1`，因为需要在命中时直接返回。
3. **与 LC 153 的关系**：153 只找最小值，用 `nums[mid]` vs `nums[right]` 判断断点位置；本题需要同时判断有序段 + target 落点，更复杂。
