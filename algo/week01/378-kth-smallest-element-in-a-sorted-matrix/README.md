# 378. 有序矩阵中第 K 小的元素

- **链接**：[LeetCode 378](https://leetcode.cn/problems/kth-smallest-element-in-a-sorted-matrix/)
- **难度**：中等
- **标签**：数组、二分查找、矩阵、排序

## 题目描述

给定一个 `n × n` 矩阵 `matrix`，其中**每行和每列**都按**非递减顺序**排列。返回矩阵中第 `k` 小的元素。

注意：与 LC 74 不同，本题只保证行和列各自递增，**不能展平为一维有序数组**。

## 示例

```
输入：matrix = [[1,5,9],[10,11,13],[12,13,15]], k = 8
输出：13
解释：排序后为 [1,5,9,10,11,12,13,13,15]，第 8 小是 13
```

```
输入：matrix = [[-5]], k = 1
输出：-5
```

## 约束

- `n == matrix.length == matrix[i].length`
- `1 <= n <= 300`
- `-10^9 <= matrix[i][j] <= 10^9`
- `1 <= k <= n^2`
