# LC 378 · 有序矩阵中第 K 小的元素 — 解题思路

## 题意

`n × n` 矩阵，行、列均递增（非严格），找第 `k` 小的元素。

## 核心思路（值域二分）

- **与下标二分的区别**：这里二分的不是下标，而是**值**。
- **check(x)**：`countLeq(x)` = 矩阵中 `≤ x` 的元素个数。`countLeq(x)` 关于 `x` 非减。
- **目标**：最小的 `x` 使得 `countLeq(x) >= k`。
- **搜索区间**：`[matrix[0][0], matrix[n-1][n-1]]`。

## countLeq 的 O(n) 实现

利用行列递增性质，从第 0 行开始、`j` 从 `n-1` 向左走：

- 对每行 `i`，找最后一个 `≤ x` 的列 `j`，该行贡献 `j + 1` 个。
- 关键：`j` **不用每行重置**，因为下一行的值更大，`j` 只会左移或不动。

总遍历量 ≤ `n + n = 2n`，即 O(n)。

## 复杂度

- **时间**：O(n · log(max - min))，二分轮数 O(log V)，每轮 countLeq O(n)。
- **空间**：O(1)。

## 易错点

1. **答案一定在矩阵中**：虽然二分的 `mid` 可能不在矩阵中，但收敛后的 `lo` 一定是矩阵中的某个值（因为 countLeq 在矩阵值处发生跳变）。
2. **`j` 不重置**：这是 O(n) 的关键，初学者容易每行从 `n-1` 重新扫，退化为 O(n²)。
3. **非严格递增**：矩阵可以有重复值，不影响 countLeq 逻辑。
