# LC 200 · 岛屿数量 — 解题思路

## 题意

给定 m x n 的字符网格，`'1'` 是陆地，`'0'` 是水。水平或垂直相邻的陆地构成一个岛屿，统计岛屿总数。

## 核心思路

- 遍历所有格子，遇到 `'1'` 时计数 +1，然后用 DFS 将该 `'1'` 所连通的所有 `'1'` 全部标记为 `'0'`（原地修改代替 visited 数组）。
- DFS 向上下左右四个方向扩展，使用方向数组 `[[0,1],[0,-1],[1,0],[-1,0]]` 是网格搜索的标配写法。
- 每次 DFS 会"淹没"一整座岛屿，因此主循环中遇到 `'1'` 的次数就是岛屿数量。

```text
for r in 0..m:
  for c in 0..n:
    if grid[r][c] == '1':
      count++
      dfs(r, c)  // 把整座岛标记为 '0'
```

## 复杂度

- **时间**：O(m * n)，每个格子最多被访问两次（主循环一次 + DFS 一次）。
- **空间**：O(m * n)，最坏情况下递归栈深度为整个网格大小（全是陆地）。

## 易错点

1. **原地修改 vs visited**：原地将 `'1'` 改为 `'0'` 可以省去 visited 数组，但会修改输入。测试时需注意对 grid 做深拷贝。
2. **边界检查**：DFS 递归前先检查行列是否越界，以及当前格子是否为 `'1'`。
3. **字符 vs 数字**：题目中 grid 元素是字符 `'1'` / `'0'`，不是数字 1 / 0。Rust 中对应 `char` 类型。
