# LC 417 · 太平洋大西洋水流问题 — 解题思路

## 题意

给定 `m x n` 高度矩阵，水从高处往低处流（相邻且 `<=` 当前高度）。太平洋在上和左边界，大西洋在下和右边界。求所有能同时流向两个大洋的格子坐标。

## 核心思路

- **正向思考**（从每个格子出发看能否到达两个洋）复杂度高，每个格子都需要一次完整 DFS。
- **反向思考**：从两个洋的边界出发，向**高处**走（`heights[nr][nc] >= heights[r][c]`），标记每个洋能到达的格子集合。最后取交集。

具体做法：

1. 从太平洋边界（第 0 行 + 第 0 列）出发 DFS，标记 `pacific[i][j] = true`
2. 从大西洋边界（第 m-1 行 + 第 n-1 列）出发 DFS，标记 `atlantic[i][j] = true`
3. 遍历所有格子，同时满足 `pacific[i][j] && atlantic[i][j]` 的即为答案

## 复杂度

- **时间**：O(m × n)，每个格子最多被两次 DFS 各访问一次。
- **空间**：O(m × n)，两个 visited 数组 + DFS 递归栈。

## 易错点

1. **方向搞反**：反向 DFS 走的是「高处」（`>=`），不是低处。正向是水往低处流，反向是逆流而上。
2. **边界初始化**：太平洋 = 上边界 + 左边界；大西洋 = 下边界 + 右边界。角落格子同时属于两个边界，不要漏掉。
3. **输出顺序**：题目不要求特定顺序，但测试时需排序后再比较。
