# LC 695 · 岛屿的最大面积 — 解题思路

## 题意

给定 m x n 整数网格，`1` 是陆地，`0` 是水。返回最大岛屿的面积（格子数）。无岛返回 0。

## 核心思路

- 与 200 类似，遍历所有格子，遇到 `1` 时用 DFS 沉岛。
- 不同之处：DFS 返回面积 —— 当前格子计 1，加上四个方向递归返回的面积之和。
- 维护全局 `maxArea`，每次 DFS 结束后更新。

```text
dfs(r, c):
  if out-of-bounds or grid[r][c] == 0: return 0
  grid[r][c] = 0
  area = 1
  for (dr, dc) in dirs:
    area += dfs(r+dr, c+dc)
  return area
```

## 复杂度

- **时间**：O(m * n)。
- **空间**：O(m * n)，递归栈最坏情况。

## 易错点

1. **DFS 返回值**：不能只用 `void`，需要累加面积返回。
2. **全是水**：没有岛屿时返回 0，初始 `maxArea = 0` 即可自然处理。
3. **数字 grid**：本题 grid 是 `number[][]` / `int[][]`，不同于 200 的 `string[][]` / `char[][]`。
