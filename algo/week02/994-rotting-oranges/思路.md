# LC 994 · 腐烂的橘子 — 解题思路

## 题意

`m x n` 网格，格子值 `0`（空）、`1`（新鲜橘子）、`2`（腐烂橘子）。每分钟腐烂橘子向四方向扩散感染。求所有新鲜橘子腐烂的最少分钟数，不可能则返回 `-1`。

## 核心思路

**多源 BFS**：

1. 遍历网格，将所有初始腐烂橘子（值为 `2`）入队，同时统计新鲜橘子数量 `fresh`。
2. 如果 `fresh == 0`，直接返回 `0`。
3. BFS 逐层扩展（每层 = 1 分钟）：取出当前层所有腐烂橘子，向四方向扩散，将新鲜橘子变为腐烂并入队，`fresh--`。
4. BFS 结束后，若 `fresh > 0` 返回 `-1`，否则返回层数（分钟数）。

```text
t=0          t=1          t=2          t=3          t=4
2 1 1        2 2 1        2 2 2        2 2 2        2 2 2
1 1 0   ->   2 1 0   ->   2 2 0   ->   2 2 0   ->   2 2 0
0 1 1        0 1 1        0 2 1        0 2 2        0 2 2
```

关键：多源 BFS 天然处理「同时扩散」——初始队列包含所有源点，每层同步推进。

## 复杂度

- **时间**：O(m * n)，每个格子最多入队一次。
- **空间**：O(m * n)，队列最坏情况全为腐烂橘子。

## 易错点

1. **初始没有新鲜橘子**：应返回 `0` 而非 `-1`。
2. **初始没有腐烂橘子但有新鲜橘子**：BFS 不会启动，最终 `fresh > 0`，返回 `-1`。
3. **分钟数计算**：BFS 层数从 `0` 开始，最后一层扩展后不再有下一层，分钟数 = 总层数 - 1（或用 `minutes` 变量在每层开始时递增）。注意初始层不算时间。
