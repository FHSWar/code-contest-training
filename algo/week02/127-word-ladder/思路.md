# LC 127 · 单词接龙 — 解题思路

## 题意

给定 `beginWord` 和 `endWord`，每次只能改变一个字母，且改变后的单词必须在 `wordList` 中。求最短转换序列的**单词数量**（含首尾），不可达返回 `0`。

## 核心思路

- **建模为图**：每个单词是一个节点，相差一个字母的两个单词之间有边。问题转化为求从 `beginWord` 到 `endWord` 的最短路径。
- **BFS + 枚举替换**：对当前单词的每个位置，尝试替换为 `a` 到 `z` 的 26 个字母。若新单词在 `wordSet` 中且未访问过，入队。
- **HashSet 加速查找**：将 `wordList` 转为 `HashSet`，单词查找 O(1)。
- **提前终止**：发现 `endWord` 时立即返回，不必等整层处理完。

```text
BFS 层序：
  hit (步数 1)
   -> hot (步数 2)
     -> dot, lot (步数 3)
       -> dog, log (步数 4)
         -> cog (步数 5) <- 命中
```

## 复杂度

- **时间**：O(M^2 * N)，其中 M 是单词长度，N 是字典大小。每个单词有 M 个位置 x 26 种替换，字符串拼接/比较 O(M)。
- **空间**：O(M * N)，HashSet 存储所有单词 + 队列。

## 易错点

1. **endWord 不在字典中**：必须先检查，否则永远找不到。
2. **beginWord 可能在字典中**：不影响正确性，但 visited 集合必须包含 `beginWord` 避免重复。
3. **返回值含义**：返回的是序列中的单词数量，不是变换次数。`hit -> cog` 需要 4 次变换，但返回 5（含首尾）。
