# LC 733 · 图像渲染 — 解题思路

## 题意

从 `(sr, sc)` 出发，将所有与起始像素颜色相同且相邻连通的像素全部改为 `color`。

## 核心思路

- 经典 Flood Fill：从 `(sr, sc)` 开始 DFS，把所有颜色为 `origColor` 的相邻像素改为 `color`。
- **关键边界**：如果 `origColor == color`，直接返回，否则 DFS 会无限递归（改完的颜色和原色一样，永远满足条件）。
- 方向数组 `[[0,1],[0,-1],[1,0],[-1,0]]`，四方向扩展。

```text
flood_fill(image, sr, sc, color):
  orig = image[sr][sc]
  if orig == color: return image
  dfs(sr, sc)
  return image

dfs(r, c):
  if out-of-bounds or image[r][c] != orig: return
  image[r][c] = color
  for (dr, dc) in dirs:
    dfs(r+dr, c+dc)
```

## 复杂度

- **时间**：O(m * n)，每个像素最多访问一次。
- **空间**：O(m * n)，递归栈最坏情况。

## 易错点

1. **origColor == color**：必须特判，否则死循环。这是本题最核心的 edge case。
2. **不需要 visited**：因为改颜色本身就标记了"已访问"（前提是 origColor != color）。
