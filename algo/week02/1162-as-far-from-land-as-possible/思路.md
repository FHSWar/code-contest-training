# LC 1162 · 地图分析 — 解题思路

## 题意

给定 `n x n` 网格，`1` 为陆地、`0` 为海洋。求所有海洋单元格中，离最近陆地最远的那个的距离（曼哈顿距离）。若全陆或全海返回 `-1`。

## 核心思路

- **多源 BFS**：把所有陆地单元格同时入队作为起点，逐层向四方扩展。每扩展一层，距离 +1。BFS 天然保证每个海洋格第一次被访问时的距离就是它到最近陆地的最短距离。
- 最后一层被访问的海洋格对应的距离即为答案。

```text
初始：所有 grid[i][j]==1 入队，dist = -1
每轮：弹出当前层所有格子，把相邻未访问的 0 标记为已访问并入队
      dist++
结束：队列为空，返回 dist
```

- 全陆地 / 全海洋时队列长度为 `n*n` 或 `0`，直接返回 `-1`。

## 复杂度

- **时间**：O(n^2)，每个格子入队出队各一次。
- **空间**：O(n^2)，队列最坏存储所有格子。

## 易错点

1. **修改原数组**：BFS 直接在 `grid` 上标记已访问（把 `0` 改为 `1`），避免额外 `visited` 数组。但测试时需要**克隆 grid**，否则用例间互相影响。
2. **`dist` 初值**：初始为 `-1`，第一轮处理的是陆地自身，处理完 `dist` 变为 `0`；后续每层 `dist++`。
3. **全陆 / 全海判定**：入队数量为 `0` 或 `n*n` 时立即返回 `-1`。
