# LC 130 · 被围绕的区域 — 解题思路

## 题意

给定 `m x n` 的 `'X'`/`'O'` 矩阵，将所有不与边界连通的 `'O'` 区域翻转为 `'X'`。原地修改，无返回值。

## 核心思路

**逆向思维**：直接找「被围绕的 `'O'`」不好做，因为需要证明与边界不连通。反过来，先找「不被围绕的 `'O'`」——即所有与边界 `'O'` 连通的格子——标记保护，剩下的 `'O'` 就是需要翻转的。

步骤：

1. 遍历矩阵四条边界，对每个 `'O'` 发起 DFS（或 BFS），将其及所有相连的 `'O'` 标记为临时字符 `'#'`。
2. 遍历整个矩阵：
   - `'O'` → `'X'`（未被标记，说明被围绕）
   - `'#'` → `'O'`（恢复，说明与边界连通）

```text
原始        标记后       最终
X X X X     X X X X     X X X X
X O O X  →  X O O X  →  X X X X
X X O X     X X O X     X X X X
X O X X     X # X X     X O X X
```

左下角 `'O'` 在边界上，DFS 将其标记为 `'#'`；中间三个 `'O'` 与边界不连通，第二步翻转为 `'X'`。

## 复杂度

- **时间**：O(m * n)，每个格子最多被访问两次（DFS 一次 + 最终遍历一次）。
- **空间**：O(m * n)，DFS 递归栈最坏情况（全 `'O'`）。BFS 写法队列同理。可改用迭代栈控制。

## 易错点

1. **边界遍历要完整**：四条边都要扫，不能只扫两条。
2. **DFS 越界与重复访问**：进入 DFS 前检查坐标合法且当前为 `'O'`，标记后不再重复入栈。
3. **原地修改**：函数无返回值，直接在输入 `board` 上操作。测试时需要先克隆原始 board 再调用、对比。
4. **全 `'O'` 矩阵**：如果整个矩阵都是 `'O'`，所有格子都与边界连通，结果不变。
