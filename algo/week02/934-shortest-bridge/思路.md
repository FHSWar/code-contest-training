# LC 934 · 最短的桥 — 解题思路

## 题意

二元矩阵中恰好有两座岛（由 `1` 连通），求将最少多少个 `0` 翻转为 `1` 能连通两岛。即求两岛之间的最短距离。

## 核心思路

分两步：**DFS 找岛 + BFS 扩展**。

1. **DFS 标记第一座岛**：遍历矩阵找到第一个 `1`，DFS 将整座岛标记为 `2`（区别于第二座岛的 `1`），同时将所有岛格加入 BFS 队列。
2. **BFS 逐层扩展**：从第一座岛的所有格子同时出发，每轮向外扩展一层。碰到 `0` 就标记为 `2` 并入队；碰到 `1` 说明到达了第二座岛，返回当前步数。

```text
Step 0: 第一座岛所有格子在队列中（标记为 2）
Step 1: 扩展一层 0 → 2，入队
Step 2: 继续扩展，碰到 1 → 返回 2
```

本质上是从一个连通分量出发的**多源 BFS 求最短距离**。

## 复杂度

- **时间**：O(n^2)，DFS + BFS 各遍历所有格子一次。
- **空间**：O(n^2)，队列 + DFS 递归栈。

## 易错点

1. **DFS 标记值**：必须用不同于 `1` 的值（如 `2`）标记第一座岛，否则 BFS 无法区分「自己的岛」和「目标岛」。
2. **BFS 返回时机**：在扩展邻居时检测到 `1` 就返回 `steps`，而不是出队时检测。出队时检测会多算一步。
3. **`break` 两层循环**：找到第一个 `1` 后需要跳出双重循环。TS 用 `found` 标志，Rust 用 `'outer: for` 标签。
