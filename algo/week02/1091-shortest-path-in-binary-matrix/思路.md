# LC 1091 · 二进制矩阵中的最短路径 — 解题思路

## 题意

在 `n x n` 二进制矩阵中，从左上角 `(0, 0)` 到右下角 `(n-1, n-1)` 找最短路径。可沿 **8 个方向**移动，只能经过值为 `0` 的格子。返回路径上的格子数量，不可达返回 `-1`。

## 核心思路

- **BFS 求最短路**：无权图中 BFS 天然给出最短路径。从 `(0, 0)` 出发，按层扩展，首次到达 `(n-1, n-1)` 时的层数即为答案。
- **8 方向**：与标准网格 BFS 的 4 方向不同，本题允许对角线移动，方向数组有 8 个元素。
- **原地标记**：访问过的格子置为 `1`，既标记已访问又避免额外空间。

```text
方向数组（8 个邻居）：
(-1,-1) (-1,0) (-1,1)
( 0,-1)   X   ( 0,1)
( 1,-1) ( 1,0) ( 1,1)
```

## 复杂度

- **时间**：O(n^2)，每个格子最多入队一次。
- **空间**：O(n^2)，队列最坏存储所有格子。

## 易错点

1. **起点或终点为 1**：必须先检查 `grid[0][0]` 和 `grid[n-1][n-1]`，否则 BFS 无法启动或永远到不了终点。
2. **n = 1 特判**：只有一个格子且为 `0` 时，路径长度为 `1`，不需要 BFS。
3. **路径长度 vs 步数**：题目要求的是路径上的格子数（包含起点），不是边数。起点算第 1 步。
4. **测试时需克隆 grid**：解法会修改 `grid` 做原地标记，测试代码必须传入副本。
